The purpose of the repository
A repository is the central place to store, organize, and manage common code and its version history. 

The steps you followed to complete the tutorial
Step 1 Install Git on my personal computer and create an account.
Step 2 Create a local Git repository on my personal computer.
Step 3 Collab with a classmate and add them to my Github repository.
Step 4 Create a new branch in my repository.
Step 5 Add a python file to my repository that print my first and last name.
Step 6 Comment on the new file.
Step 7 Push the new branch to Github.
Step 8 Create a Pull Request and assign my collaborator as the reviewer.
Step 9 Wait for my collaborator to review and approve my PR.
Step 10 After approval merge the new branch into the main branch.
